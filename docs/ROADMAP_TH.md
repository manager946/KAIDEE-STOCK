# KAIDEE-STOCK — แผนพัฒนาต่อ

## สิ่งที่ยืนยัน
- ระบบเดิมเป็นเว็บแอป Google Apps Script ที่ใช้ Google Sheets (ตามไฟล์ส่งต่องาน)
- ยังไม่ได้รับ Source Apps Script และ Spreadsheet ID ที่ยืนยันว่าใช้จริง
- โปรเจกต์ GitHub นี้ไม่ใช่ระบบ production

## ระยะ 1 ตรวจระบบเดิม (ห้ามแก้ข้อมูล)
1. รับลิงก์ Apps Script Editor และ Google Sheets ที่ใช้อยู่จริง
2. สำรองโค้ดและ Google Sheets ก่อนแก้ไข
3. ตรวจชื่อแท็บ คอลัมน์ ความสัมพันธ์ระหว่าง OrderID กับเลขเอกสาร
4. ตรวจบทบาทผู้ใช้ การจอง/เบิก/จ่าย/ยกเลิก และรหัสภายใน

## ระยะ 2 ความถูกต้องของสต๊อก
- เพิ่ม movement log และป้องกันบันทึกซ้ำด้วย fulfillment key
- ยกเลิกใบเบิกต้องคืนยอดที่ถูกต้อง โดยไม่ลบ audit trail
- ทดสอบกดซ้ำ หลายผู้ใช้ สินค้าไม่พอ และการคืนยอด

## ระยะ 3 เอกสารและการใช้งาน
- พรีวิว/ดาวน์โหลด/พิมพ์ PDF บนมือถือและคอมพิวเตอร์
- ระบบสิทธิ์ Public / Staff / Admin ตามระบบจริง
- Dashboard และรายงาน

**ห้าม Deploy โค้ดทดลองแทนระบบจริง** จนกว่าจะทดสอบบน staging สำเร็จ
